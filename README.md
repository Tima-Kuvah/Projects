# Projects
В этом репозитории собраны мои учебные проекты. 
Реализованные проекты на данный момент - Arithmetic Expression Parser, Tic-Tac-Toe.

## Проекты

###Arithmetic expression parser
Парсер арифметических выражений, построенный методом рекурсивного спуска.
В проекте реализованы: 

* объектная модель арифметических выражений.
* бинарные и унарные операции
* учет приоритетов и ассоциативности операторов
* обработка синтаксических ошибок и арифметических переполнений
* строковое представление с минимальным количеством скобок.

На данный момент проект построен под тестирующую преподавательскую систему - она включает в себя тесты и внешние интерфейсы, служащие связью между моими классами и тестирующей системы. 

[Перейти к проекту](java/arithmetic-expression-parser)

###Tic-Tac-Toe
Консольная реализация игры крестики нолики с настраиваемыми параметрами игрового поля.

Проект поддерживает:
* Прямоугольное поле
* несколько типов игроков
* проведение как отдельных матчей, так и турниров

В проекте разделены логика игры, состояние доски и поведения игроков.

[Перейти к проекту](java/tic-tac-toe)

###Custom scanner
Раелиазция упрощенного буферного сканера для чтения. Сканер поддерживает работу со строками, файлами и потоками ввода. Правила определения токена определяется при помощи предикатов.

[Перейти к проекту](java/scanner)
