# Projects

В этом репозитории собраны мои учебные проекты.
Реализованные на данный момент проекты — Arithmetic Expression Parser, Tic-Tac-Toe и Custom Scanner.

## Проекты

### Arithmetic Expression Parser

Парсер арифметических выражений, построенный методом рекурсивного спуска.

В проекте реализованы:

* объектная модель арифметических выражений;
* бинарные и унарные операции;
* учёт приоритетов и ассоциативности операторов;
* обработка синтаксических ошибок и арифметических переполнений;
* строковое представление с минимальным количеством скобок.

На данный момент проект адаптирован под преподавательскую тестирующую систему. Она включает в себя тесты и внешние интерфейсы, связывающие мою реализацию с системой тестирования.

[Перейти к проекту](java/arithmetic-expression-parser)

### Tic-Tac-Toe

Консольная реализация игры «Крестики-нолики» с настраиваемыми параметрами игрового поля.

Проект поддерживает:

* прямоугольное поле;
* несколько типов игроков;
* проведение как отдельных матчей, так и турниров.

В проекте разделены логика игры, состояние доски и поведение игроков.

[Перейти к проекту](java/tictactoe)

### Custom Scanner

Реализация упрощённого буферизированного сканера для чтения данных. Сканер поддерживает работу со строками, файлами и потоками ввода. Правила определения токенов задаются при помощи предикатов.

[Перейти к проекту](java/scanner)
