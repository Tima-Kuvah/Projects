# Arithmetic Expression Parser

Учебный проект на Java, объединяющий несколько этапов работы с арифметическими выражениями: построение объектной модели выражения, вычисление результата, вывод с минимальным количеством скобок и разбор строки методом рекурсивного спуска.

## Возможности

Основная версия парсера поддерживает:

- целочисленные константы;
- переменные с индексами: `$0`, `$1`, `$2` и далее;
- бинарные операции `+`, `-`, `*`, `/`, `min`, `max`;
- унарный минус;
- унарные операции `reverse`, `digits`, `floor`, `ceiling`;
- вычисление выражения по списку значений переменных;
- полное строковое представление выражения через `toString()`;
- представление с минимальным количеством скобок через `toMiniString()`;
- сравнение выражений через `equals()` и `hashCode()`.

В проекте также находится отдельная версия парсера с проверяемой арифметикой. В текущей реализации она поддерживает операции `+`, `-`, `*`, `/`, унарный минус, `high` и `low`, а также обрабатывает:

- арифметические переполнения;
- деление на ноль;
- некорректные константы и индексы переменных;
- ошибки в структуре выражения и расстановке скобок.

## Пример использования

```java
import expression.ListExpression;
import expression.parser.ExpressionParser;

import java.util.List;

public class Main {
    public static void main(String[] args) {
        ListExpression expression = new ExpressionParser().parse(
                "reverse $0 + 10 min $1",
                List.of("$0", "$1")
        );

        System.out.println(expression.toMiniString());
        System.out.println(expression.evaluate(List.of(123, 500)));
    }
}
```

Результат:

```text
reverse $0 + 10 min $1
331
```

## Авторство

Интерфейсы задания и тестирующая инфраструктура были предоставлены в рамках учебного курса.

Самостоятельно реализованы:

- классы арифметических выражений и операций;
- вычисление выражений;
- формирование строкового представления с учётом приоритетов операций;
- парсер методом рекурсивного спуска;
- проверяемые арифметические операции;
- обработка синтаксических и вычислительных ошибок.

## Требования

- JDK 17 или новее;

## Сборка

### PowerShell

Из каталога проекта:

```powershell
New-Item -ItemType Directory -Force out | Out-Null
javac -encoding UTF-8 -d out (Get-ChildItem -Recurse src -Filter *.java | ForEach-Object FullName)
```

### Linux/macOS

```bash
mkdir -p out
find src -name "*.java" -print0 | xargs -0 javac -encoding UTF-8 -d out
```

## Запуск тестов

При запуске тестирующей системы необходимо включить assertions с помощью параметра `-ea`.

Проверка объектной модели выражений:

```bash
java -ea -cp out expression.ExpressionTest hard Base
```

Проверка основной версии парсера для варианта `3637`:

```bash
java -ea -cp out expression.parser.ParserTest hard 3637
```

## Текущее состояние

Основная версия парсера и объектная модель выражений проходят предоставленные тесты. Версия с проверяемой арифметикой является отдельным этапом учебного проекта и в текущем состоянии настроена на набор операций `high` и `low`.
