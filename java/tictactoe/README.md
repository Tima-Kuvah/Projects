# Tic-Tac-Toe

Консольная реализация игры «Крестики-нолики» на Java с настраиваемым размером поля, несколькими типами игроков и турнирным режимом.

## Возможности

В текущей реализации поддерживаются:

* прямоугольное игровое поле размером `n × m`;
* настраиваемая длина выигрышной последовательности `k`;
* игра между двумя выбранными игроками;
* проведение турнира между несколькими игроками;
* включение пошагового отображения партий;
* определение победы по горизонтали, вертикали и диагоналям;
* определение ничьей при заполнении игрового поля.

## Типы игроков

В проекте реализованы три типа игроков:

* `HumanPlayer` — получает ход от пользователя;
* `SequentialPlayer` — выбирает первую доступную клетку;
* `RandomPlayer` — выбирает случайную свободную клетку.

Все игроки реализуют общий интерфейс `IPlayer`, поэтому в игру можно добавлять новые стратегии без изменения основной логики матча.

## Турнирный режим

В турнирном режиме каждый игрок проводит с каждым соперником две партии, меняясь очерёдностью хода.

За результаты начисляются очки:

* победа — 3 очка;
* ничья — 1 очко каждому игроку;
* поражение — 0 очков.

После завершения турнира выводится таблица участников, отсортированная по количеству набранных очков.

## Структура проекта

Основные классы:

* `Main` — настройка и запуск игры или турнира;
* `Game` — управление ходом отдельной партии;
* `TicTacToeBoard` — хранение доски, проверка и применение ходов;
* `TTTBoardState` — копия текущего состояния доски, передаваемая игрокам;
* `Tournament` — организация турнира и подсчёт очков;
* `IPlayer` — общий интерфейс игроков;
* `HumanPlayer`, `SequentialPlayer`, `RandomPlayer` — реализации игроков.

Логика игры, состояние доски и стратегии игроков разделены между отдельными классами.

## Запуск

Проект протестирован с Java 21.

Точка входа:

```text
game.Main
```

Для запуска из IntelliJ IDEA необходимо открыть проект и запустить метод `main` из класса:

```text
src/game/Main.java
```

Сборка и запуск через PowerShell из каталога проекта:

```powershell
javac -d out (Get-ChildItem -Recurse -Filter *.java src | ForEach-Object FullName)
java -cp out game.Main
```

После запуска программа предложит:

1. выбрать обычную игру или турнир;
2. включить или отключить пошаговый вывод;
3. указать размеры поля и длину выигрышной последовательности;
4. выбрать типы и количество игроков.

## Назначение проекта

Проект был реализован для практики объектно-ориентированного программирования, работы с интерфейсами, разделения ответственности между классами и реализации различных стратегий поведения объектов.
