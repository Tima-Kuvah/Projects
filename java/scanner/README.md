# Custom Scanner

Учебная реализация буферизированного сканера на Java.

Класс предназначен для последовательного чтения символов и выделения токенов из строки, файла или входного потока. Правила начала и продолжения токена задаются с помощью `Predicate<Character>`.

## Возможности

Сканер поддерживает:

* чтение данных из строки;
* чтение из `InputStream` с указанием кодировки;
* чтение из файла по `Path` с указанием кодировки;
* буферизированное чтение данных;
* поиск следующего токена по заданному предикату;
* чтение токенов в пределах одной строки;
* автоматическое закрытие источника данных через интерфейс `Closeable`.

Размер внутреннего буфера составляет 8192 символа.

## Основные методы

```java
boolean hasNext(Predicate<Character> begin)
```

Ищет следующий символ, удовлетворяющий условию начала токена.

```java
boolean hasNextInLine(Predicate<Character> begin)
```

Ищет следующий токен в пределах текущей строки.

```java
String next(Predicate<Character> middle)
```

Считывает токен, пока его символы удовлетворяют переданному условию.

```java
boolean hasNextLine()
```

Проверяет, остались ли непрочитанные данные.

## Пример использования

```java
import java.io.IOException;

public class Main {
    public static void main(String[] args) throws IOException {
        try (MyScanner scanner = new MyScanner("Hello, world! 123")) {
            while (scanner.hasNext(Character::isLetter)) {
                String word = scanner.next(Character::isLetter);
                System.out.println(word);
            }
        }
    }
}
```

Результат:

```text
Hello
world
```

Начальный и последующие символы токена могут проверяться разными предикатами. Например, это позволяет отдельно определить допустимый первый символ числа и символы, которые могут находиться внутри него.

## Сборка

Проект собирается с помощью Java 21:

```bash
javac -d out src/main/MyScanner.java
```

Скомпилированный класс будет находиться в каталоге `out`.

## Структура

```text
scanner/
└── src/
    └── main/
        └── MyScanner.java
```

## Ограничения текущей реализации

* сканер предназначен для чтения строковых токенов и не содержит отдельных методов для преобразования значений в числовые типы;
* разделитель строк определяется через `System.lineSeparator()`;
* перед вызовом `next` предполагается предварительная проверка через `hasNext` или `hasNextInLine`.

Проект реализован для практики работы с буферизированным вводом, границами буфера, потоками и функциональными интерфейсами Java.
